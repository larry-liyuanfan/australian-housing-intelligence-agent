System Overview / Data Pipeline

This project presents a cloud-style analytics pipeline for understanding Australian housing insecurity. Online discussion data is processed with NLP methods and compared with official rental indicators.

Sources

YouTube, GDELT/news, official rent indicators.

Harvesting

Collected and normalised source records.

Processing

Keyword, sentiment, topic modelling.

Storage

ElasticSearch-style indexed records.

Analysis

Trends, platforms, official comparison.

Frontend

Interactive dashboard frontend.

Cross-platform Discussion Volume

Compares housing-related discussion volume across public discourse platforms.

API: /api/housing/volume-by-platform

Overall Sentiment Distribution

Shows the overall sentiment distribution of housing-related discussion.

API: /api/analysis/housing/sentiment-summary

Platform Sentiment Comparison

Compares sentiment patterns across different public discussion platforms.

API: /api/analysis/housing/sentiment-by-platform

Sentiment Trend Over Time

Tracks how housing-related sentiment changes over time.

API: /api/analysis/housing/sentiment-over-time?interval=month

Keyword Distribution

Shows the most frequent housing-related keywords and topics.

API: /api/analysis/housing/top-query-keywords

Regional Discussion Distribution

Visualises cleaned regional housing discussion distribution. City-level and state-level mentions are shown separately to avoid mixing geographic levels.

API: /api/analysis/housing/by-region-cleaned?source_size=2000&output_size=100
Interpretation: Counts represent regional mentions in public discourse, not housing severity.

Official Housing Overview

Summarises official housing evidence source coverage.

API: /api/official/overview
Interpretation: This chart uses a log scale because official source row counts vary greatly. It shows data coverage, not housing severity.

Housing Word Cloud

Shows the most frequent meaningful words extracted from recent housing-related public discourse records. Generic English stopwords, conversational filler, and unrelated news entities are removed on the frontend so the cloud surfaces substantive topics rather than function words.

API: /api/analysis/housing/word-cloud

Conclusion and Limitations

The dashboard demonstrates how backend APIs can connect online discussion data, NLP analysis, and official rental indicators into one frontend presentation.

  • API outputs depend on backend and ElasticSearch availability.
  • Sentiment analysis is used as a baseline NLP method.
  • Official housing data provides real-world context for online discussion trends.
