# Decision record

## DR-001 — Keep official and discussion evidence separate

Official tables and online discussion are generated by different processes. They are indexed, filtered, cited, and labeled separately. The Agent may compare them but cannot merge hit counts into a population statistic.

## DR-002 — Typed tools instead of free-form ReAct

A long ReAct prompt does not constrain execution. Six Pydantic contracts and a registry bound the action space, make invalid arguments measurable, and prevent arbitrary Elasticsearch DSL.

## DR-003 — Explicit state machine with bounded recovery

The orchestration is inspectable and capped at four tool executions. Duplicate detection, timeouts, a single retry, and empty-result broadening prevent silent loops and unbounded cost.

## DR-004 — Deterministic offline path first

The public repository must run without credentials. BM25, a local dense surrogate, RRF and feature reranking form a reproducible baseline; live Model Studio and Elasticsearch are adapters, not hidden prerequisites.

## DR-005 — Synthetic public fixtures only

Raw social text, handles, URLs, screenshots, team identities and student records are excluded. Offline preprocessing uses an allowlist, redaction and salted IDs. The salt and output remain in protected storage.

## DR-006 — Resource isolation on Aliyun SG

The existing Trip deployment is out of scope. Housing uses a separate Compose name, network, volumes and loopback ports with explicit CPU/memory/PID caps. No GPU model is self-hosted on the 4-vCPU/7-GB machine.
